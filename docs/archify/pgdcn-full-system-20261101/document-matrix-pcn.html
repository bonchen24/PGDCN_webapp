Bảng hồ sơ/file theo bước PCN

Danh mục hồ sơ và DOCX manifest là hai catalog khác nhau. Required/optional phản ánh baseline code; runtime override và workflow PUBLISHED chưa xác minh. PCN dùng 9 bước của map biến thể. MISSING / PRESENT / WAIVED là trạng thái checklist; PRESENT cần currentVersionId đã attach. File sinh còn draft tới confirm-to-dossier; upload chưa attach không đạt; review/verify là gate riêng; phiên trước được giữ nhưng đã superseded. Không đọc dữ liệu case.

Điều hướng UI: Dossier detail tóm tắt tối đa ba file thiếu tại bước đang chọn; “Xem danh sách tài liệu” mở checklist đầy đủ. Requirement vẫn theo snapshot/template. (đối chiếu source commit 081f0a48945dce3c6f419804ce4e6b956e50a147).
