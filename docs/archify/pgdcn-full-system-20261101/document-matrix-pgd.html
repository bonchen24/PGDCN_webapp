Bảng hồ sơ/file theo bước PGD

Danh mục hồ sơ và DOCX manifest là hai catalog khác nhau. Required/optional phản ánh baseline code; runtime override và workflow PUBLISHED chưa xác minh. PGD có đủ 12 bước cho từng profile. MISSING khi chưa có file asset liên kết; PRESENT khi đã attach; WAIVED chỉ khi có record và chưa xác minh đường mutation. Checklist PGD không có trạng thái riêng DRAFT / GENERATED / CONFIRMED; upload rời chưa đạt package/hash gate. Không đọc dữ liệu case.

Điều hướng UI: Khi bị chặn hoặc chỉ xem/đang tải/lỗi, CTA chỉ mở workbench; action theo dòng dùng đúng role, trạng thái chỉ đổi qua API gate. Requiredness vẫn phụ thuộc productGroup/profile/template. (đối chiếu source commit 348b855a57595eec2646bb462e5c29571c3be501).
